# OWNGAME HELPI

Android starter project for the PylaAI project link.

## Build an APK

1. Open the **Actions** tab in this repository.
2. Select **Build OWNGAME HELPI APK** and run it with **Run workflow**, or push a commit to the default `main` or `master` branch.
3. When the workflow succeeds, open its run and download the `OWNGAME-HELPI-debug-apk` artifact.
4. Extract the ZIP to get `app-debug.apk`.

## Important

PylaAI is a desktop project, not an Android app. A direct rename or format conversion cannot make desktop-specific code run on Android. This starter APK only displays project information and links to the original repository; it does not automate gameplay or interact with a game.

Original project: https://github.com/PylaAI/PylaAI
